AES-256 Encrypt & Decrypt

Lock text or files with a passphrase or a 256-bit key, and unlock them again. Everything happens inside this browser tab: nothing you type or drop here is uploaded or stored.

  • PBKDF2-SHA256 × 600,000
  • 12-byte random nonce

How it works

Cipher
AES with a 256-bit key in GCM mode. GCM encrypts and adds a 16-byte authentication tag, so a wrong key or any altered byte is rejected instead of producing garbage.
Passphrase
Turned into a 256-bit key with PBKDF2-HMAC-SHA256, 600,000 iterations and a fresh 16-byte random salt per message. Text is Unicode-normalized (NFC) first, so accented characters typed on different keyboards give the same key.
256-bit key
32 bytes from the browser's secure random generator, used directly. Faster than a passphrase and impossible to guess, but you must store it.
Nonce
12 fresh random bytes per message, so encrypting the same text twice gives different output.
Header
Format marker, flags, salt and nonce are authenticated together with the ciphertext (GCM additional data), so none of them can be edited.
Files
The original file name is encrypted along with the contents. Results save as base64 text (.aes.txt), which survives email and chat apps.

import base64, hashlib, struct, unicodedata
from cryptography.hazmat.primitives.ciphers.aead import AESGCM

def a256_open(text, passphrase=None, key=None):
    """Text in, text out. Files return (name, bytes).
    key: 32 bytes, e.g. bytes.fromhex("...")"""
    b64 = "".join(l.strip() for l in text.splitlines()
                  if not l.strip().startswith("-----"))
    blob = base64.b64decode(b64 + "=" * (-len(b64) % 4))
    if blob[:4] != b"A256" or blob[4] != 1:
        raise ValueError("not an A256 v1 message")
    flags, p = blob[5], 6
    if flags & 1:  # passphrase-derived key
        iters = struct.unpack(">I", blob[p:p + 4])[0]
        salt = blob[p + 4:p + 20]
        p += 20
        pw = unicodedata.normalize("NFC", passphrase).encode()
        key = hashlib.pbkdf2_hmac("sha256", pw, salt, iters, 32)
    iv = blob[p:p + 12]
    p += 12
    # header bytes are the GCM additional data
    plain = AESGCM(key).decrypt(iv, blob[p:], blob[:p])
    if flags & 2:  # file: 2-byte name length, name, contents
        n = struct.unpack(">H", plain[:2])[0]
        return plain[2:2 + n].decode(), plain[2 + n:]
    return plain.decode()

Format A256 v1, built on the browser's Web Crypto API with no third-party crypto code. Closing this tab clears the passphrase, key and text.
